- 목차의 "React Router DOM" : v7부터 패키지 이름이 react-router로 바뀌었음을 먼저 알려 준다. (App.jsx [순서01] 주석)

---------------------------------------------------------------------
1교시 (50분) - 라우팅 기본
---------------------------------------------------------------------
[순서01] SPA와 라우팅 (10분)
  - 질문 던지기 : "지금까지 만든 앱은 주소가 하나였다. 상품 상세 페이지는 어떻게 만들까?"
  - 판서 : 주소 /products/3 → <ProductDetail /> (주소와 컴포넌트를 짝짓기)

[순서02] BrowserRouter, Routes, Route (10분)
  - 시연 : 주소창에 /about, /products 직접 입력 → 해당 화면

[순서03] Link와 NavLink (10분)  → Home.jsx, Layout.jsx
  - 시연 : 홈의 Link 클릭 → 즉시 이동 / a 태그 클릭 → 화면이 깜빡이며 새로고침
           (Network 탭에서 a 태그는 문서 전체를 다시 받는 것 확인)
  - 시연 : 메뉴 이동 시 현재 메뉴만 빨간 굵은 글씨 (NavLink isActive)
           홈 NavLink의 end를 지우면 → 모든 페이지에서 "홈"도 active → 원복

[순서06] 중첩 라우트와 Outlet (20분)  → Layout.jsx
  ※ [순서04]보다 먼저 설명하면 이해가 쉽다. (메뉴가 모든 페이지에 보이는 이유)
  - 판서 : Layout(메뉴 + Outlet + 푸터) 안에 자식 페이지가 끼워진다
  - 포인트 : index 라우트, 자식 path는 / 없이

---------------------------------------------------------------------
2교시 (50분) - 동적 라우트, 이동, 404, 쿼리 + 실습
---------------------------------------------------------------------
[순서04] 동적 라우트 (10분)  → ProductDetail.jsx
  - 시연 : 상품 클릭 → /products/2 / 주소를 /products/99로 바꾸면 "찾을 수 없습니다"
  - 포인트 : useParams의 값은 문자열 → Number(id)

[순서05] useNavigate (5분)
  - 시연 : [뒤로] → navigate(-1) / [구매하기] → 홈 이동 후 브라우저 뒤로 가기 → 상세로 안 돌아감(replace)

[순서07] 404 (3분)
  - 시연 : /abc 입력 → 404 + 요청한 주소 표시

[순서08] useSearchParams (7분)  → Products.jsx
  - 시연 : 정렬 버튼 → 주소가 ?sort=price 로 바뀜 → 새로고침해도 정렬 유지 / 주소 복사해서 새 탭에 붙여 넣기
  - 포인트 : useState는 새로고침하면 사라지지만 쿼리 스트링은 남는다.

실습 (25분) : Practice.jsx 문제 1 ~ 4
  - main.jsx에서 Practice.jsx로 바꾸면 주소가 그대로 남아 있을 수 있다 → 주소를 "/"로 바꾸고 시작

---------------------------------------------------------------------
예상 질문 / 자주 막히는 곳
---------------------------------------------------------------------
- "useNavigate() may be used only in the context of a <Router>" → BrowserRouter 밖에서 훅 사용
- Link to="products/1"(상대 경로)와 to="/products/1"(절대 경로) 혼동 → 처음에는 항상 / 로 시작하게
- 배포 후 새로고침하면 404 → 서버가 모든 주소를 index.html로 보내도록 설정 필요 (개발 서버는 자동 처리)
