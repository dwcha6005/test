1교시 (50분) - 프로젝트 만들기와 실행 흐름, 컴포넌트, JSX 규칙
---------------------------------------------------------------------
[순서01] 프로젝트 구조와 실행 흐름 (20분)
  - 학생들과 함께 새 프로젝트를 만든다. (15_module_vite에서 배운 그대로)
      npm create vite@latest my-first-react -- --template react
      cd my-first-react → npm install → npm run dev
  - 시연 : index.html → main.jsx → App.jsx 순서로 파일을 열며 연결 고리를 짚는다.
           개발자 도구 Elements 탭에서 <div id="root"> 안에 내용이 들어간 것 확인
  - 시연 : App.jsx 글자를 바꾸고 저장 → 새로고침 없이 바로 반영
  - 포인트 : 기존 자료(CRA)와 다른 점 - .jsx 확장자, npm run dev, index.html 위치
  ※ 이후 수업은 react-lessons 프로젝트로 진행 (main.jsx에서 챕터 선택)

[순서02] 컴포넌트 (10분)
  - 시연 : Hello 컴포넌트를 소문자 hello로 바꾸면 화면에 나오지 않음 → 대문자 규칙
  - 포인트 : 컴포넌트 = JSX를 return 하는 함수. 같은 컴포넌트를 여러 번 재사용 가능

[순서03] JSX 규칙 (20분)
  - 시연 : <input /> 의 / 를 지우면 오류 화면 → 오류 메시지 읽는 법
           Fragment(<></>)를 지우고 section 두 개를 나란히 return → 오류
           label을 클릭하면 체크박스가 선택됨 (htmlFor)
  - 포인트 : class → className, for → htmlFor

2교시 (50분) - 표현식, 조건부 렌더링, 스타일 + 실습
---------------------------------------------------------------------
[순서04] 표현식 (10분)
  - 시연 : boolean 그대로 → [ ] 빈칸 / String() → [true]
           {user} 주석을 풀면 "Objects are not valid as a React child" 오류 → 원복
  - 포인트 : { } 안에는 "값"만. if, for는 안 된다. (조건은 [순서05], 반복은 ch04)

[순서05] 조건부 렌더링 (10분)
  - 시연 : && 함정 - unread가 0이라 "잘못된 예 : [0]" 이 보인다
  - 포인트 : 둘 중 하나 → 삼항 / 보일까 말까 → && / 경우가 많으면 → if + return

[순서06] 스타일 (5분)
  - 시연 : isError를 false로 바꿔 색상 변경 확인
  - 포인트 : style={{ }} 의 이중 중괄호 의미, 카멜 표기법

실습 (25분) : Practice.jsx 문제 1 ~ 4
  - main.jsx에서 Practice.jsx로 바꿔 정답 확인
  - 학생들은 자기 프로젝트(my-first-react)의 App.jsx에서 풀게 한다.
