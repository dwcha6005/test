1교시 (50분) - 파일 분리, props 기본
---------------------------------------------------------------------
[순서01] 컴포넌트 파일 분리 (15분)  → components/Header.jsx, Footer.jsx
  - 시연 : App.jsx 안에 있던 Header 함수를 잘라 새 파일로 옮기는 과정을 직접 보여 준다.
           export default를 빼면 → import 오류 / 경로 오타 → "Failed to resolve import"
  - 포인트 : 파일 이름 = 컴포넌트 이름(대문자). 기존 자료의 footer.js(소문자), componenet(오타) 주의

[순서02] props 전달 (15분)  → UserInfo.jsx 의 UserInfoBasic
  - 시연 : 콘솔에 찍힌 props 객체 확인 { name: "차동원", location: "부산" }
  - 포인트 : 문자열은 "", 나머지는 { }

[순서03] 구조 분해 + 기본값 (15분)  → UserInfo.jsx 의 UserInfo
  - 시연 : 기본값 foodList = [] 를 지우면 → 이영희 카드에서 "Cannot read properties of undefined (reading 'length')"
  - 포인트 : 구조 분해는 key 이름과 같아야 한다. 전달 안 될 수 있는 값은 기본값
