1교시 (50분) - useEffect
---------------------------------------------------------------------
[순서01] useEffect 기본 (10분)
  - 시연 : 콘솔에 "1. 렌더링 중" → "2. useEffect 실행" 순서 / 클릭하면 탭 제목 변경
  - 포인트 : 컴포넌트 함수 = 화면 계산, useEffect = 그린 뒤 바깥 세상과 연결(부수 효과)

[순서02] 의존성 배열 (15분)  ★ 가장 중요
  - 판서 : 없음 → 매번 / [] → 처음 한 번 / [a] → 처음 + a가 바뀔 때
  - 시연 : count 버튼 → [count] 로그만 추가 / 입력 → [text] 로그만 추가
  - 포인트 : StrictMode 때문에 처음 로그가 두 번 찍힐 수 있다 (정상)

[순서03] 정리 함수 (10분)
  - 시연 : [시계 숨기기] → 콘솔 "타이머 정리" / 다시 보이기 → "타이머 시작"
           setInterval 안에 console.log("tick")을 넣고 return () => clearInterval(id)를 지운 뒤 숨기면
           → 시계가 사라졌는데도 콘솔에 tick이 계속 찍힘 (보이기/숨기기를 반복하면 타이머가 계속 늘어남) → 원복
  - 포인트 : 12_async 01 "setInterval은 반드시 멈출 방법을 함께" 와 같은 원리

[순서04] 데이터 불러오기 (15분)
  - 시연 : 새로고침 → "불러오는 중..." → 회원 10명 / Network 탭에서 users 요청 확인
           URL을 /userz로 바꾸면 → "요청 실패 (404)"
  - 포인트 : useEffect(async () => ...) 는 안 된다 → 안에 async 함수를 만들고 호출
            11_Form 04 메모장, 12_async 03의 상태 패턴이 그대로 React로 옮겨진 것

2교시 (50분) - 다시 요청, useRef + 실습
---------------------------------------------------------------------
[순서05] 의존성이 바뀌면 다시 요청 (10분)
  - 시연 : 회원 선택을 바꿀 때마다 게시글 3개가 바뀜
           Network 탭 "Slow 3G" + 빠르게 회원 변경 → 마지막 회원 글만 남음 (ignore)

[순서06] useRef - 포커스 (5분)  ★ 기존 자료 수정 부분
  - 시연 : 빈 칸으로 Enter → 입력창에 커서 / 입력 후 Enter → 목록 추가, 입력창 비움, 포커스 유지
  - 포인트 : 기존 자료처럼 ref로 value를 직접 비우면 state와 화면이 달라진다. 비우기는 setText("")

[순서07] useRef - 값 저장 (5분)
  - 시연 : [ref 증가] 여러 번 → 화면 그대로 (콘솔만 증가) → [state 증가] → 그때 ref 값이 화면에 반영
  - 판서 : 일반 변수 / state / ref 비교표
