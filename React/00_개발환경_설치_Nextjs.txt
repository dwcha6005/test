1. Next.js란? Vite + React와 무엇이 다른가
---------------------------------------------------------------------
React      : 화면(UI)을 만드는 "라이브러리"
Vite       : React 코드를 개발 서버로 보여 주고 빌드해 주는 "개발 도구"
Next.js    : React로 웹사이트 전체를 만드는 "프레임워크"
             (라우팅, 서버에서 화면 만들기, 데이터 가져오기, 최적화가 기본 포함)

| 항목            | Vite + React (ch01 ~ ch12)          | Next.js (ch13)                        |
| 화면을 만드는 곳 | 브라우저 (빈 HTML을 받은 뒤 JS가 그림) | 서버에서 HTML을 완성해서 보냄           |
| 라우팅          | React Router를 따로 설치             | 폴더를 만들면 주소가 생김 (app 폴더)     |
| 데이터 가져오기 | useEffect + fetch                    | 서버 컴포넌트에서 await fetch           |
| 검색 엔진 노출   | 불리함 (첫 HTML이 비어 있음)          | 유리함                                 |
| 기본 주소       | localhost:5173                       | localhost:3000                        |

→ Next.js는 Vite 프로젝트(react-lessons) 안에 넣지 않고 "별도 프로젝트"로 만든다.


---------------------------------------------------------------------
2. Next.js 프로젝트 만들기
---------------------------------------------------------------------
※ Node.js 20.9 이상이 필요하다. (node -v 로 확인)

① react-lessons "밖"의 폴더(예: D:\Git)에서 터미널을 열고 입력

    npx create-next-app@latest next-lessons

   - "Ok to proceed? (y)" 가 나오면 y

② 질문에 답한다. (화살표 키 / Enter, Yes·No는 좌우 화살표)
   버전에 따라 질문 문구와 순서가 조금 다를 수 있다. 아래 핵심만 맞추고 나머지는 기본값(Enter)

   - 추천 기본값을 쓸지 묻는 질문이 나오면 → 직접 고르는 쪽(customize) 선택
   - TypeScript            → No
   - ESLint                → Yes
   - Tailwind CSS          → No
   - src/ directory        → No
   - App Router            → Yes
   - import alias (@/*)    → 기본값 그대로 (Enter)

③ 설치는 자동으로 진행된다. (npm install을 따로 하지 않아도 된다)


---------------------------------------------------------------------
3. 실행하기
---------------------------------------------------------------------
    cd next-lessons
    npm run dev

- 터미널에 나온 http://localhost:3000 을 Ctrl + 클릭
- 끄기 : Ctrl + C
- react-lessons(5173)와 동시에 켜 둬도 된다. 터미널 오른쪽 위 + 버튼으로 터미널을 하나 더 연다.
- VS Code에서 "파일 → 폴더 열기 → next-lessons" 로 열어서 작업하면 편하다.

주의
- Next.js 서버 컴포넌트의 console.log는 브라우저 콘솔이 아니라 "VS Code 터미널"에 찍힌다.


---------------------------------------------------------------------
4. 폴더 구조
---------------------------------------------------------------------
    next-lessons/
    ├── node_modules/
    ├── package.json
    ├── next.config.mjs     ← Next.js 설정
    ├── jsconfig.json       ← @/ 경로 별칭 설정
    ├── public/             ← 이미지 등 정적 파일
    └── app/
        ├── layout.js       ← 모든 페이지 공통 틀 (<html>, <body>)
        ├── page.js         ← 주소 "/"
        ├── globals.css
        └── about/
            └── page.js     ← 주소 "/about"

★ 폴더 이름 = 주소, 그 안의 page.js = 화면
  app 안에 contact 폴더를 만들고 page.js를 넣으면 /contact 주소가 바로 생긴다.

템플릿이 만든 app/page.js, globals.css 내용은 지우고 새로 작성해도 된다.


---------------------------------------------------------------------
5. 자주 묻는 질문
---------------------------------------------------------------------
Q. npx 실행 시 npm.ps1 / npx.ps1 을 로드할 수 없다고 나와요.
A. "00_개발환경_설치.txt" 4번의 PowerShell 설정을 한다.

Q. useState를 쓰니 "only works in Client Components" 에러가 나요.
A. 파일 맨 첫 줄(import보다 위)에 "use client"; 를 쓴다.

Q. 상세 페이지에서 params.id 가 undefined 예요.
A. Next.js 15부터 params는 Promise다.  const { id } = await params;  로 꺼낸다.

Q. localStorage is not defined 에러가 나요.
A. 서버에서도 한 번 실행되기 때문이다. useEffect 안에서 사용한다.

Q. 3000번 포트가 사용 중이라고 나와요.
A. 다른 터미널에서 이미 실행 중이다. Ctrl + C로 끄거나, Next가 알려 주는 다른 주소(3001)로 접속한다.
