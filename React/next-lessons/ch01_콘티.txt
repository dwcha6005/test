---------------------------------------------------------------------
예상 질문 / 자주 막히는 곳
---------------------------------------------------------------------
- params.id 가 undefined → await params 누락
- "useState only works in Client Components" → 파일 맨 위 "use client" (import보다 위)
- localStorage is not defined → 서버에서 실행됨. useEffect 안으로
- 서버 컴포넌트 파일을 고쳤는데 콘솔에 로그가 없다 → 터미널을 봐야 한다
- "React Router를 Next.js에서도 쓰나요?" → 아니다. Next.js는 폴더 라우팅을 사용
