실습 6. Sticky 메뉴

아래 내용을 충분히 만들어 스크롤해보세요.

CSS Position을 공부하고 있습니다.

relative는 자신의 원래 위치를 기준으로 이동합니다.

absolute는 부모 요소를 기준으로 위치를 지정할 수 있습니다.

fixed는 브라우저 화면에 고정됩니다.

sticky는 스크롤 위치에 따라 고정됩니다.

Position을 이용하면 다양한 UI를 만들 수 있습니다.

쇼핑몰 상품 카드에도 position이 많이 사용됩니다.
