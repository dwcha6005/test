HTML · CSS · BOOTSTRAP FINAL PROJECT

LOCAL TABLE 웹사이트 구현

제공된 완성 화면(target.html)을 참고하여 동네 원데이 클래스 소개 및 신청 웹사이트를 구현하세요.

시험 조건
작업 시간: 180분 / 총점: 100점
HTML, CSS, Bootstrap에서 배운 내용만 사용합니다. 외부 템플릿을 복사하지 말고 직접 작성하세요.

1. 기본 조건

  • 파일명은 practice.html로 저장하고, CSS는 내부 style 또는 별도 CSS 파일로 작성합니다.
  • Bootstrap 5.3 이상 CDN을 사용하고, Bootstrap JavaScript가 필요한 기능은 bundle을 연결합니다.
  • 페이지는 PC, 태블릿, 모바일에서 가로 스크롤 없이 보여야 합니다.
  • 의미에 맞는 HTML5 시맨틱 태그를 사용하고 이미지에는 적절한 alt를 작성합니다.
  • 링크는 실제 섹션으로 연결합니다. 의미 없는 href="#" 사용은 금지합니다.
  • 콘텐츠와 색상은 주제에 맞게 작성하되, 레이아웃·기능·반응형 동작은 기준 화면과 최대한 비슷하게 구현합니다.

2. 필수 구현 항목

① 헤더와 내비게이션 (10점)

  • 브랜드 로고, 4개 이상의 메뉴, 신청 버튼을 배치합니다.
  • Bootstrap Navbar의 모바일 토글을 구현하고, 메뉴는 해당 섹션으로 이동해야 합니다.
  • 스크롤 시 상단에 유지되는 내비게이션을 구현합니다.

② 메인 Carousel (12점)

  • 서로 다른 이미지와 제목·설명을 가진 슬라이드를 3개 이상 만듭니다.
  • 이전/다음 버튼, 인디케이터, 자동 전환 중 2가지 이상을 구현합니다.
  • 이미지는 영역을 가득 채우고 제목은 이미지 위에 읽기 쉽게 배치합니다.

③ 추천 클래스 카드 (14점)

  • 클래스 카드 3개 이상을 Bootstrap Grid로 배치합니다.
  • 카드마다 이미지, 카테고리 배지, 제목, 설명, 시간 또는 가격, 상세 보기 버튼을 넣습니다.
  • PC에서는 3열, 태블릿에서는 2열, 모바일에서는 1열로 배치합니다.
  • CSS hover 효과를 적용하되 콘텐츠가 움직여도 겹치거나 잘리지 않아야 합니다.

④ Modal 상세 보기 (12점)

  • 각 카드의 상세 보기 버튼을 누르면 Bootstrap Modal이 열려야 합니다.
  • Modal에는 클래스명, 설명, 가격 또는 참여 안내, 닫기 버튼이 있어야 합니다.
  • 가능하면 클릭한 카드의 데이터가 Modal에 반영되도록 구현합니다.
  • 닫기 버튼, 바깥 영역 클릭 또는 ESC로 닫히는 기본 동작을 유지합니다.

⑤ 소개 영역과 반응형 레이아웃 (10점)

  • 이미지와 소개 글을 2단 레이아웃으로 배치합니다.
  • 수치 또는 특징을 2개 이상 시각적으로 강조합니다.
  • 모바일에서는 이미지와 텍스트가 자연스럽게 세로로 쌓이도록 합니다.

⑥ 일정 테이블 (10점)

  • 날짜, 클래스, 시간, 장소, 잔여석, 신청 항목이 있는 테이블을 만듭니다.
  • 테이블 헤더와 행을 구분하고, Bootstrap hover 및 정렬 클래스를 적절히 사용합니다.
  • 좁은 화면에서도 레이아웃이 깨지지 않도록 반응형 테이블을 적용합니다.
  • 잔여석 또는 마감 상태는 Badge 등으로 구분합니다.

⑦ Accordion FAQ (8점)

  • 질문과 답변을 3개 이상 작성합니다.
  • Bootstrap Accordion으로 열고 닫히게 하고, 한 번에 하나씩 열리는 동작을 적용합니다.

⑧ 신청 폼과 유효성 표시 (14점)

  • 이름, 연락처, 이메일, 클래스 선택, 인원 선택, 요청 사항, 개인정보 동의 항목을 만듭니다.
  • 각 입력 요소와 label을 연결하고 필수 입력에는 required를 적용합니다.
  • Bootstrap Form 클래스를 사용하고, 입력 오류가 있을 때 피드백을 표시합니다.
  • 제출과 초기화 버튼을 제공하고, 실제 서버 전송이 되지 않는 경우 화면용임을 표시합니다.

⑨ CSS 커스터마이징과 마무리 (10점)

  • Bootstrap 기본 스타일을 그대로 두지 말고 브랜드 색상, 글꼴, 간격, 테두리, 버튼 등을 일관성 있게 수정합니다.
  • CSS 변수 또는 재사용 가능한 클래스를 2개 이상 사용합니다.
  • hover/focus 상태를 고려하고, 제목 크기·여백·이미지 비율이 일관적이어야 합니다.
  • Footer와 상단 이동 버튼을 포함합니다.

3. 제출 전 확인

참고: 이미지와 Bootstrap CDN은 인터넷 연결이 필요합니다. 완성 화면은 target.html을 확인하세요.
