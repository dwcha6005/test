Bootstrap Accordion

Accordion은 내용을 접었다 펼치면서 보여주는 Bootstrap 컴포넌트이다.

1. 기본 Accordion

HTML은 웹 페이지의 구조와 내용을 작성하는 마크업 언어이다.

CSS는 웹 페이지의 색상, 크기, 배치 등의 디자인을 담당한다.

JavaScript는 웹 페이지에 동적인 기능과 상호작용을 추가한다.
