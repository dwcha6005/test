HTML Video 속성 심화 실습

이번 수업에서는 video 태그의 여러 속성을 조합하여 영상 재생 방식을 제어하고, 실제 웹페이지에서 사용할 수 있는 영상 영역을 만들어 본다.

1. 불리언 속성 이해하기

HTML 속성 중에는 값 자체보다 속성의 존재 여부가 중요한 불리언 속성이 있다.

<video controls></video>
<video controls="controls"></video>

두 코드는 모두 controls가 활성화된 상태다.

다음처럼 작성해도 controls는 비활성화되지 않는다.

<video controls="false"></video>

HTML에서는 controls 속성이 존재하기 때문에 활성화된다. 비활성화하려면 속성 자체를 제거해야 한다.

controls가 있는 영상

controls가 없는 영상

실습 1. controls="false"로 작성한 영상과 controls 속성을 완전히 제거한 영상의 차이를 확인하시오.

2. autoplay와 muted

autoplay는 페이지가 열렸을 때 영상의 자동 재생을 시도하는 속성이다. 그러나 브라우저 정책에 따라 자동 재생이 차단될 수 있다.

<video
    src="https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4"
    autoplay
    muted
    playsinline
></video>
  • autoplay : 자동 재생을 시도한다.
  • muted : 소리를 끈 상태로 시작한다.
  • playsinline : 지원하는 모바일 환경에서 페이지 안에서 재생하도록 요청한다.

자동 재생 + 음소거

브라우저가 자동 재생을 허용하는 경우에 재생된다. 자동 재생 여부는 환경에 따라 달라질 수 있다.

자동 재생은 광고 영상, 배경 영상, 짧은 시각 효과 등에 활용될 수 있다. 다만 소리와 함께 자동 재생하는 방식은 사용자 경험을 해칠 수 있어 브라우저에서 제한하는 경우가 많다.

실습 2. autoplay를 제거해 보고, 다시 muted를 제거했을 때 자동 재생이 어떻게 달라지는지 확인하시오.

3. loop 속성

loop는 영상이 끝났을 때 처음부터 반복 재생하도록 설정한다.

<video src="videos/sample.mp4" controls loop></video>

반복 재생 영상

영상을 끝까지 재생하여 처음부터 다시 재생되는지 확인하자.

loop는 반복 재생이 필요한 짧은 영상이나 배경 효과에 유용하다. 단, 자동으로 반복 재생하는 것과 자동으로 처음 재생하는 것은 서로 다른 동작이다.

실습 3. loop 속성을 제거하고 반복 재생 여부를 비교하시오.

4. poster 속성

poster는 영상이 재생되기 전에 표시할 대표 이미지를 지정한다.

<video
    src="https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4"
    controls
    width="480"
    poster="images/cover.jpg"
></video>

poster에는 영상 파일이 아닌 이미지 파일의 경로를 지정한다. 대표 이미지는 영상 파일 자체의 첫 프레임과는 별개다.

poster 적용

이미지 주소가 유효한 경우 영상 재생 전 대표 이미지가 표시된다.

poster는 온라인 강의 썸네일, 홍보 영상의 첫 화면, 영상 로딩 전 미리보기 등에 활용할 수 있다.

실습 4. poster를 제거하고 영상이 재생되기 전 표시되는 화면을 비교하시오.

5. preload 속성

preload는 브라우저가 영상 데이터를 어느 정도 미리 불러올지 알려주는 힌트다.

값 의미
none 미리 로딩하지 않도록 요청
metadata 영상 길이 등 메타데이터를 우선 불러오도록 요청
auto 재생에 필요한 데이터를 미리 불러올 수 있도록 요청 
<video src="videos/sample.mp4" controls preload="none"></video>
<video src="videos/sample.mp4" controls preload="metadata"></video>
<video src="videos/sample.mp4" controls preload="auto"></video>

preload는 강제 명령이 아니다. autoplay가 있거나 브라우저의 로딩 정책이 다른 경우 실제 동작은 달라질 수 있다.

실습 5. preload 값을 바꾸고 개발자 도구의 Network 탭에서 영상 요청과 전송량을 비교하시오. 캐시를 포함한 환경에 따라 결과가 달라질 수 있다.

6. width와 height

width와 height는 영상 요소의 표시 크기를 지정한다. 두 속성을 함께 지정할 때는 원본 영상의 비율을 고려해야 한다.

원본 비율에 맞춘 너비

너비와 높이를 모두 지정

두 번째 영상처럼 원본 비율과 지정한 영역의 비율이 다르면 영상이 찌그러져 보일 수 있다.

CSS의 object-fit 속성을 사용하면 영상이 영역 안에 표시되는 방식을 제어할 수 있다.

video {
    width: 480px;
    height: 270px;
    object-fit: cover;
}

cover는 영역을 채우면서 비율을 유지하므로 영상의 일부가 잘릴 수 있다. contain은 전체 영상이 보이도록 맞추며 빈 공간이 생길 수 있다.

실습 6. object-fit을 cover와 contain으로 변경하여 영상의 표시 결과를 비교하시오.

7. source와 type

source 태그는 video 요소 안에서 재생할 파일과 미디어 유형을 지정한다.

<video controls width="480">
    <source src="videos/sample.webm" type="video/webm">
    <source src="videos/sample.mp4" type="video/mp4">
    브라우저에서 영상을 재생할 수 없습니다.
</video>

브라우저는 소스를 순서대로 검토하여 재생 가능한 형식을 선택하려고 한다. 하지만 컨테이너 형식만으로 재생 가능 여부가 결정되는 것은 아니며 내부 코덱과 서버 설정도 영향을 준다.

실습 7. source 태그를 두 개 작성한 예제에서 첫 번째 소스 경로를 잘못 지정해 보고, 두 번째 소스가 재생 가능한 경우 어떤 동작을 하는지 확인하시오. 실제 결과는 브라우저와 파일 형식에 따라 달라질 수 있다.

8. 대체 콘텐츠

video 태그 안에 작성한 일반 텍스트는 브라우저가 video 요소를 지원하지 않는 경우 등에 대체 콘텐츠로 사용될 수 있다.

<video controls>
    <source src="videos/sample.mp4" type="video/mp4">
    브라우저에서 영상을 재생할 수 없습니다.
</video>

단순히 파일 경로가 잘못되었거나 영상 다운로드에 실패했다고 해서 대체 텍스트가 반드시 표시되는 것은 아니다. 일반적인 로딩 오류는 브라우저의 영상 UI를 통해 표시될 수 있다.

9. 오류 확인 실습

다음 코드는 일부러 존재하지 않는 파일 경로를 지정한 예제다.

<video src="videos/not-found.mp4" controls></video>

파일이 존재하지 않으면 영상이 재생되지 않는다. 개발자 도구를 열고 Network 탭에서 해당 파일 요청의 상태를 확인해 보자.

  • 404 : 요청한 파일을 찾을 수 없음
  • 403 : 접근 권한이 거부됨
  • 200 : 서버가 요청에 정상 응답했음을 의미하지만, 미디어 재생까지 보장하지는 않음

파일 요청이 성공했더라도 지원하지 않는 코덱이나 잘못된 파일 형식 때문에 재생에 실패할 수 있다.

실습 8. 올바른 파일 경로와 잘못된 파일 경로를 각각 작성하고 개발자 도구에서 차이를 확인하시오.

10. 종합 실습 : 영상 소개 카드 만들기

실습 조건

  1. 영상 제목을 h2 태그로 작성한다.
  2. video 태그로 영상을 삽입한다.
  3. 재생 조작 UI를 표시한다.
  4. 영상 너비를 100%로 지정하고 최대 너비를 640px로 제한한다.
  5. 영상 비율이 유지되도록 CSS를 작성한다.
  6. 영상 대표 이미지를 지정한다.
  7. 영상 아래에 설명 문단을 작성한다.
  8. 카드의 여백, 테두리, 배경색을 CSS로 디자인한다.

완성 예시

<div class="video-card">
    <h2>오늘의 영상</h2>
    <video controls poster="images/cover.jpg">
        <source src="videos/sample.mp4" type="video/mp4">
        브라우저에서 영상을 재생할 수 없습니다.
    </video>
    <p>영상에 대한 간단한 설명을 작성합니다.</p>
</div>
.video-card {
    max-width: 680px;
    padding: 20px;
    border: 1px solid #ddd;
    border-radius: 12px;
    background: #f9f9f9;
}
.video-card video {
    display: block;
    width: 100%;
    height: auto;
}
