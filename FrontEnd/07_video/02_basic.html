HTML Video 실습

이번 수업에서는 video 태그를 직접 작성하고 속성을 변경하면서 영상의 재생 방식과 화면 표시가 어떻게 달라지는지 확인한다.

1. 가장 기본적인 video 태그

video 태그는 HTML 문서에 동영상을 삽입하는 요소다. 먼저 영상 파일의 주소를 src 속성으로 연결해 보자.

<video src="https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4"></video>

위 코드를 실행하면 영상 요소는 존재하지만 재생 버튼과 같은 기본 조작 UI가 표시되지 않는다.

사용자가 직접 재생할 수 있도록 controls 속성을 추가한다.

<video src="https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4" controls></video>

실행 결과

재생, 일시정지, 볼륨 등의 조작 UI를 확인해 보자.

실습 1. controls 속성을 삭제한 경우와 추가한 경우를 비교하시오.

2. src와 controls

2-1. src 속성

src는 재생할 영상 파일의 주소를 지정한다.

<video src="영상파일주소" controls></video>

영상 파일 주소는 로컬 프로젝트의 상대 경로 또는 외부 서버의 URL을 사용할 수 있다.

<video src="videos/sample.mp4" controls></video>

위 예제는 현재 HTML 파일을 기준으로 videos 폴더 안의 sample.mp4 파일을 찾는다.

2-2. controls 속성

controls는 브라우저가 기본 재생 조작 UI를 표시하도록 한다.

두 영상의 차이를 확인하자. 두 번째 영상은 기본 재생 조작 UI가 없다.

실습 2. 두 번째 영상에도 controls 속성을 추가하고 결과를 비교하시오.

3. width와 height

width와 height는 영상 요소의 표시 너비와 높이를 지정한다.

<video src="https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4" controls width="320"></video>

<video src="https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4" controls width="640"></video>

너비 320px

너비 640px

width만 지정하면 브라우저는 영상의 원래 비율을 고려해 높이를 계산할 수 있다.

반면 width와 height를 모두 지정하면 지정된 표시 영역에 맞춰진다. 원본 비율과 지정한 비율이 다를 경우 CSS 설정에 따라 영상이 찌그러져 보일 수 있다.

<video src="https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4" controls width="640" height="200"></video>

너비와 높이를 모두 지정한 경우

원본 영상의 비율과 표시 영역의 비율이 다를 때 어떤 현상이 나타나는지 확인하자.

실습 3. 너비를 480px로 변경하고, 너비와 높이를 모두 지정했을 때의 차이를 확인하시오.

4. poster 속성

poster는 영상이 재생되기 전에 표시할 대표 이미지를 지정한다.

<video
    src="https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4"
    controls
    width="640"
    poster="https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.webm"
></video>

주의: poster에는 이미지 파일을 지정해야 한다. 위 코드의 flower.webm은 영상 파일이므로 poster 예제로 적합하지 않다. 아래에서는 실제 이미지 URL을 사용한다.

<video
    src="https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4"
    controls
    width="640"
    poster="https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.jpg"
></video>

poster 적용 예시

영상이 재생되기 전 표시되는 이미지를 확인하자. 외부 이미지 주소가 변경되거나 제공되지 않으면 표시되지 않을 수 있다.

실습 4. poster 속성을 제거한 뒤 영상이 재생되기 전의 화면을 비교하시오.

5. autoplay, muted, loop

세 속성은 영상의 자동 재생, 음소거, 반복 재생 동작을 설정한다.

<video
    src="https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4"
    autoplay
    muted
    loop
    playsinline
></video>
  • autoplay : 자동 재생을 시도한다.
  • muted : 음소거 상태로 시작한다.
  • loop : 영상이 끝나면 반복 재생한다.
  • playsinline : 지원하는 모바일 환경에서 페이지 안에서 재생하도록 요청한다.

자동 재생 및 반복 재생

브라우저 정책에 따라 자동 재생 여부는 달라질 수 있다. 자동 재생을 시도할 때 muted를 함께 사용하는 이유를 생각해 보자.

실습 5. muted를 제거한 뒤 자동 재생 여부를 확인하시오. 그다음 loop를 제거하고 영상이 끝난 뒤의 동작을 비교하시오.

6. preload 속성

preload는 브라우저가 영상 데이터를 미리 불러오는 방식에 대한 힌트다.

<video src="영상파일주소" controls preload="none"></video>
<video src="영상파일주소" controls preload="metadata"></video>
<video src="영상파일주소" controls preload="auto"></video>
  • none : 미리 로딩하지 않도록 요청한다.
  • metadata : 길이 등 미디어 정보를 우선 불러오도록 요청한다.
  • auto : 재생에 필요한 데이터를 미리 불러올 수 있도록 요청한다.

preload는 브라우저가 반드시 그대로 따라야 하는 명령은 아니다. 네트워크 상황이나 autoplay 설정 등에 따라 실제 동작이 달라질 수 있다.

실습 6. preload 값을 바꾸어 보고 개발자 도구의 Network 탭에서 영상 파일 요청과 데이터 전송량을 비교하시오. 캐시와 브라우저 정책에 따라 결과가 달라질 수 있다.

7. source 태그

source는 video 요소 안에서 재생할 미디어 파일과 형식을 지정한다.

<video controls width="640">
    <source src="videos/sample.mp4" type="video/mp4">
    브라우저에서 영상을 재생할 수 없습니다.
</video>

source를 사용하면 여러 형식의 파일을 제공할 수 있다.

<video controls>
    <source src="videos/sample.webm" type="video/webm">
    <source src="videos/sample.mp4" type="video/mp4">
    브라우저에서 영상을 재생할 수 없습니다.
</video>

브라우저는 재생 가능한 소스를 선택하려고 한다. 단, 파일의 실제 코덱과 서버 응답 등도 재생 가능 여부에 영향을 준다.

8. 영상 파일 경로 실습

실제 프로젝트에서는 영상 파일을 별도의 폴더에 저장하고 상대 경로로 연결할 수 있다.

project/
├── 02_video_basic.html
└── videos/
    └── sample.mp4

위 구조라면 다음과 같이 작성한다.

<video src="videos/sample.mp4" controls width="640"></video>

경로가 잘못되었거나 파일이 존재하지 않으면 영상이 재생되지 않는다. 개발자 도구의 Network 탭에서 파일 요청 결과를 확인하면 원인을 찾는 데 도움이 된다.

완성 예시

<h1>오늘의 영상</h1>
<video
    src="videos/sample.mp4"
    controls
    width="640"
    poster="images/cover.jpg"
></video>
<p>이번 영상에서는 웹에서 동영상을 삽입하는 방법을 알아봅니다.</p>

위 코드는 HTML 구조의 예시다. 실제 프로젝트에서는 파일 경로를 본인의 폴더 구조에 맞게 수정해야 한다.
