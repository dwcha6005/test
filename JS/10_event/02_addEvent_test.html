이벤트 처리 응용 실습

addEventListener()를 활용해 실제 웹 서비스의 기능을 구현하세요.

실습 1. 쇼핑몰 상품 실시간 검색

검색어를 입력하면 상품 목록이 즉시 필터링되도록 구현하세요.

  • 검색어 입력 시 상품명을 비교합니다.
  • 검색어를 포함하지 않는 상품은 숨깁니다.
  • 검색어를 지우면 모든 상품이 다시 표시되어야 합니다.
  • 검색 결과가 없으면 안내 문구를 표시합니다.
상품 검색

상품 5개

기계식 키보드

89,000원

무선 마우스

35,000원

게이밍 헤드셋

59,000원

노트북 거치대

28,000원

키보드 손목 받침대

15,000원

검색 결과가 없습니다.

실습 2. 고객 문의 글자 수 확인

고객센터 문의 작성 화면에서 사용하는 글자 수 확인 기능을 구현하세요.

  • 입력할 때마다 현재 글자 수를 표시합니다.
  • 최대 글자 수는 100자입니다.
  • 100자를 초과하면 경고 문구를 표시합니다.
  • 100자 이하로 돌아오면 경고 문구를 숨깁니다.
문의 내용을 입력해 주세요. 0 / 100자

입력 가능한 글자 수를 초과했습니다.

실습 3. 쿠폰 코드 검증 및 할인 적용

쿠폰 코드를 입력하면 유효성을 확인하고, 적용 버튼을 눌렀을 때 할인 결과를 표시하세요.

  • 유효한 쿠폰 코드는 WELCOME10입니다.
  • 입력할 때마다 쿠폰 코드의 유효성을 검사합니다.
  • 대소문자는 구분하지 않습니다.
  • 유효한 코드일 때만 할인 적용 버튼을 활성화합니다.
  • 적용 버튼을 누르면 50,000원 상품의 10% 할인 결과를 표시합니다.

쿠폰 코드를 입력해 주세요.

상품 금액 50,000원
할인 금액 0원
최종 결제 금액 50,000원
