JavaScript 이벤트 기초 실습

각 기능의 요구사항을 읽고 버튼을 클릭했을 때 실행될 함수를 구현하세요.

문제 1. 비밀번호 표시 / 숨기기

로그인 화면에서 사용자가 입력한 비밀번호를 확인할 수 있도록 구현하세요.

  • 버튼을 클릭하면 비밀번호가 보이도록 변경하세요.
  • 다시 클릭하면 비밀번호가 숨겨지도록 변경하세요.
  • 버튼 문구도 현재 상태에 맞게 변경하세요.
문제 2. 상품 수량과 재고 제한

상품 재고는 5개입니다. 구매 수량을 변경하는 기능을 구현하세요.

상품명: 무선 마우스

남은 재고: 5개

구매 수량: 1개

구매 수량을 선택하세요.

  • 수량은 최소 1개, 최대 5개입니다.
  • 범위를 벗어나면 수량을 변경하지 마세요.
  • 재고가 부족하거나 최소 수량에 도달하면 안내 문구를 출력하세요.
문제 3. 할인 쿠폰 적용

상품 금액에 쿠폰 할인을 적용하는 기능을 구현하세요.

상품 금액: 50,000원

쿠폰: 10% 할인

할인 적용 전: 50,000원

  • 버튼을 클릭하면 10% 할인 금액을 계산하세요.
  • 할인된 최종 금액을 화면에 출력하세요.
  • 정답에서는 버튼을 한 번 누르면 할인 결과가 표시되도록 구현합니다.
문제 4. 주문 금액에 따른 배달비

주문 금액에 따라 배달비를 계산하세요.

음식 주문 금액: 18,000원

배달비 기준: 20,000원 이상이면 무료

배달비를 확인하세요.

  • 주문 금액이 20,000원 이상이면 배달비는 0원입니다.
  • 20,000원 미만이면 배달비는 3,000원입니다.
  • 최종 결제 금액도 함께 출력하세요.
문제 5. 고객센터 문의 안내

문의 유형에 따라 고객에게 다른 안내 문구를 표시하세요.

문의 유형을 선택하세요.

  • 배송: 배송 조회 페이지에서 현재 위치를 확인할 수 있습니다.
  • 환불: 주문 내역에서 환불 신청을 진행할 수 있습니다.
  • 결제: 결제 내역에서 승인 여부를 확인할 수 있습니다.
문제 6. 출근 상태 변경

직원의 출근 상태를 변경하는 기능을 구현하세요.

현재 상태: 출근 전

출근 버튼을 클릭하세요.

  • 출근 처리 버튼을 클릭하면 상태를 출근으로 변경하세요.
  • 퇴근 처리 버튼을 클릭하면 상태를 퇴근으로 변경하세요.
  • 각 버튼에 맞는 처리 완료 메시지를 출력하세요.
문제 7. 예약 인원 관리

식당 예약 인원을 조절하는 기능을 구현하세요.

예약 인원: 2명

최대 예약 인원은 8명입니다.

  • 예약 인원은 최소 1명, 최대 8명입니다.
  • 인원 변경 시 화면의 숫자를 갱신하세요.
  • 최소 또는 최대 인원을 넘으려고 하면 안내 메시지를 출력하세요.
문제 8. 게시글 공개 / 비공개

관리자 페이지에서 게시글 공개 상태를 변경하는 기능을 구현하세요.

게시글: 10월 신규 서비스 안내

공개 상태: 공개

  • 현재 공개 상태가 공개라면 비공개로 변경하세요.
  • 현재 비공개라면 공개로 변경하세요.
  • 상태와 함께 변경 완료 메시지를 출력하세요.
