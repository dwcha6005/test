addEventListener()

이벤트를 등록하고 관리하는 방법을 학습합니다.

1. 기존 onclick 방식

HTML에 이벤트 처리 코드를 직접 연결하는 방식입니다.

버튼을 클릭하세요.

2. 주문 처리

주문 처리 버튼을 클릭하면 주문 접수 결과를 표시합니다.

아직 주문을 접수하지 않았습니다.

3. 하나의 버튼에 여러 기능 연결

버튼 하나를 클릭했을 때 서로 다른 두 기능이 실행되도록 합니다.

아직 설정을 저장하지 않았습니다.

실행 기록이 없습니다.

4. 이벤트 리스너 관리

특정 기능의 이벤트 리스너를 등록하거나 제거합니다.

점검 알림이 등록되어 있습니다.

시스템 점검 버튼을 클릭해 보세요.
