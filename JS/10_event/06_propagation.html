JavaScript Event Propagation

개발자 도구(F12)의 Console 탭에서 실행 순서를 확인하세요.

1. 이벤트 버블링(Bubbling)

가장 안쪽 버튼을 클릭하고 부모 요소까지 이벤트가 전달되는 순서를 확인하세요.

Outer (바깥 영역)
Middle (중간 영역)
Inner (안쪽 영역)

2. 캡처링(Capturing)과 버블링(Bubbling)

같은 버튼을 클릭해도 리스너가 등록된 단계에 따라 실행 순서가 달라집니다.

Outer (부모 영역)
Middle (자식 영역)

3. stopPropagation()

버튼을 클릭했을 때 버튼의 이벤트가 부모 요소까지 전파되지 않도록 합니다.

Outer (바깥 영역)
Inner (안쪽 영역)

4. stopImmediatePropagation()

하나의 버튼에 등록된 여러 이벤트 리스너의 실행 결과를 비교합니다.

Outer (부모 영역)
