==========================================================================
 [실습 시험] 회원가입 폼 자바스크립트 구현
==========================================================================
■ 제공 파일
  - join.html : 회원가입 화면 (수정 금지)
  - data.js   : 가입된 회원 목록 (수정 금지)
                [ { "id": "admin", "name": "관리자", ... }, { "id": "hong", ... }, ... ]
                → fetch("data.js") 로 요청해서 아이디 중복확인에 사용

■ 실행 방법
  - fetch() 는 HTML 파일을 더블클릭해서 열면 동작하지 않음
    → VS Code 에서 join.html 을 Live Server 로 실행할 것

■ 제출 파일
  - join.js (join.html 과 같은 폴더)

--------------------------------------------------------------------------
 [작성 규칙]
--------------------------------------------------------------------------
  1) join.html 은 수정하지 않는다.
  2) 이벤트는 addEventListener() 로 연결한다.
  3) 요소는 document.querySelector() 로 가져온다.
  4) var 대신 const / let 을 사용한다.
  5) 메시지 색은 style.color 대신 class 로 바꾼다.
       예) checkIdResult.className = "msg success"   (success 초록 / warning 주황 / error 빨강)

--------------------------------------------------------------------------
 [기능 요구사항]
--------------------------------------------------------------------------

 1. 아이디 중복확인 (id="userId", 메시지 id="checkIdResult")
    - 키를 눌렀다 뗄 때마다(keyup) 검사 (앞뒤 공백 제거)
    - 5 ~ 10글자가 아니면 : "5 ~ 10글자 사이 입력 필수!" (error)
    - 길이가 맞으면 fetch("data.js") 로 회원 목록을 받아 검사
        · 같은 아이디가 있음 : "이미 사용 중인 아이디 입니다!" (error)
        · 없음               : "사용 가능한 아이디!"          (success)
    - 중복확인 통과 여부를 변수(idOk)에 저장한다.
      (아이디가 바뀌면 idOk 를 다시 false 로)

 2. 비밀번호 (id="passwd", 메시지 id="checkPasswdResult")
    - 입력할 때마다(input) 검사
    - 10 ~ 20자리가 아니면 : "10 ~ 20자리 입력 필수!" (error)
    - 영문, 숫자, 특수문자(!@#$%) 외의 문자가 있으면
        : "영문, 숫자, 특수문자(!@#$%)만 사용 가능!" (error)
    - 대문자 / 소문자 / 숫자 / 특수문자 중 사용한 종류 수로 표시
        · 4가지 : "안전 - 4가지 조합 사용" (success)
        · 3가지 : "보통 - 3가지 조합 사용" (warning)
        · 2가지 : "위험 - 2가지 조합 사용" (error)
        · 1가지 : "불가 - 영문 대/소문자, 숫자, 특수문자 중 2가지 이상 조합!" (error)
    - 비밀번호를 고치면 비밀번호 확인도 다시 검사

 3. 비밀번호 확인 (id="passwd2", 메시지 id="checkPasswd2Result")
    - 입력할 때마다(input) 검사
    - 비어 있음 : 메시지 지우기
    - 같음      : "비밀번호 확인 완료!" (success)
    - 다름      : "비밀번호 다름!"      (error)

 4. 주민번호 (id="jumin1", id="jumin2")
    - 숫자 외의 문자를 입력하면 바로 지운다.
    - 앞자리 6자리를 입력하면 뒷자리로 커서 이동

 5. 휴대폰 (id="phone", 메시지 id="checkPhoneResult")
    - 입력할 때마다(input) 검사
    - 비어 있음            : 메시지 지우기
    - 010-0000-0000 형식   : "올바른 휴대폰 번호!"           (success)
    - 형식이 아님          : "010-0000-0000 형식으로 입력!"  (error)
      힌트) 정규식  /^010-[0-9]{4}-[0-9]{4}$/

 6. 주소검색 (id="btnSearchAddress")
    - 카카오(다음) 우편번호 API 사용 (스크립트는 join.html 에 이미 있음)
      new daum.Postcode({ oncomplete: function(data) { ... } }).open();
    - 주소 선택 시
        우편번호(id="postcode") ← data.zonecode
        기본주소(id="address1") ← data.address
        상세주소(id="address2") 로 커서 이동

 7. 이메일 도메인 (id="emailDomain")
    - 선택한 값을 email2 에 넣는다.
    - "직접입력" 선택     : email2 읽기전용 해제 + email2 로 커서 이동
    - 그 외 도메인 선택   : email2 읽기전용

 8. 취미 전체선택 (id="checkAll")
    - 전체선택을 체크하면 취미 4개 모두 체크, 해제하면 모두 해제

 9. 가입 (submit)
    - 아래 순서대로 검사해서, 처음 틀린 항목의 메시지를 alert 로 띄우고
      그 항목으로 커서 이동 + 제출 취소 (e.preventDefault())
    - 모두 통과하면 그대로 제출

      | 순서 | 검사 내용                          | 알림 메시지                        | 커서 이동        |
      |------|------------------------------------|------------------------------------|------------------|
      |  1   | 이름이 비어 있음                   | 이름 입력 필수!                    | userName         |
      |  2   | 아이디가 비어 있음                 | 아이디 입력 필수!                  | userId           |
      |  3   | 중복확인 통과 못 함 (idOk)         | 사용 가능한 아이디를 입력하세요!   | userId           |
      |  4   | 비밀번호가 비어 있음               | 패스워드 입력 필수!                | passwd           |
      |  5   | 비밀번호와 비밀번호 확인이 다름    | 비밀번호 확인 필수!                | passwd2          |
      |  6   | 주민번호 앞자리가 6자리가 아님     | 주민번호 앞 6자리 필수!            | jumin1           |
      |  7   | 주민번호 뒷자리가 7자리가 아님     | 주민번호 뒤 7자리 필수!            | jumin2           |
      |  8   | 휴대폰이 010-0000-0000 형식 아님   | 휴대폰 번호 확인 필수!             | phone            |
      |  9   | 우편번호가 비어 있음               | 주소검색 필수!                     | btnSearchAddress |
      | 10   | 상세주소가 비어 있음               | 상세주소 입력 필수!                | address2         |
      | 11   | 이메일 아이디가 비어 있음          | 이메일 입력 필수!                  | email1           |
      | 12   | 이메일 도메인이 비어 있음          | 이메일 도메인 입력 필수!           | email2           |
      | 13   | 직업 미선택                        | 직업 선택 필수!                    | job              |
      | 14   | 취미를 2개 미만 선택               | 취미 2개 이상 선택 필수!           | hobby1           |
      | 15   | 가입동기가 비어 있음               | 가입동기 입력 필수!                | motivation       |
      | 16   | 가입동기가 10글자 미만             | 가입동기 10글자 이상 입력 필수!    | motivation       |

    ※ 검사는 validateForm(values) 함수로 만들고,
       틀리면 { focus: "요소 id", message: "메시지" }, 모두 통과하면 null 을 반환한다.
