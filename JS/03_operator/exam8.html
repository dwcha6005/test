JavaScript 비트 연산과 쉬프트 연산

1. 비트와 2진수

비트(Bit)는 0 또는 1을 표현하는 가장 작은 정보 단위이다.

바이트(Byte)는 일반적으로 8비트로 구성된다.

  • 10진수 : 0~9 사용
  • 2진수 : 0과 1 사용
  • 16진수 : 0~9, A~F 사용

2진수는 각 자리가 2의 거듭제곱을 의미한다.

2진수 1011
= 1 × 2³ + 0 × 2² + 1 × 2¹ + 1 × 2⁰
= 8 + 0 + 2 + 1
= 11

2진수 11010
= 1 × 16 + 1 × 8 + 0 × 4 + 1 × 2 + 0 × 1
= 26

2. 비트 연산이란?

비트 연산은 숫자를 2진수로 보고 각 비트 단위로 처리하는 연산이다.

10진수 5 = 0101
10진수 3 = 0011

  0101
& 0011
------
  0001

결과 : 1

JavaScript에서 일반적인 Number 비트 연산은 값을 32비트 정수로 변환한 뒤 처리한다. 따라서 비트 연산의 처리 방식은 일반적인 Number 산술 연산과 다르다.

3. 음수 표현과 2의 보수

컴퓨터는 비트로 양수와 음수를 표현해야 한다. JavaScript의 일반적인 Number 비트 연산은 부호 있는 32비트 정수로 변환해 처리하며, 음수는 2의 보수 방식으로 표현된다.

8비트 기준으로 -5 만들기

1단계. +5를 8비트로 표현
00000101

2단계. 모든 비트를 반전
11111010

3단계. 1을 더함
  11111010
+ 00000001
----------
  11111011

결과 : -5

비트를 반전한 뒤 1을 더하는 방식이 2의 보수이다.

8비트 부호 있는 정수의 범위는 -128부터 127까지이다. 가장 왼쪽 비트는 부호를 포함한 값의 표현에 관여한다.

참고로 8비트는 원리를 설명하기 위한 예시이고, JavaScript의 일반적인 Number 비트 연산은 32비트를 사용한다.

4. 기본 비트 연산자

연산자 이름 규칙
& AND 두 비트가 모두 1이면 1
| OR 하나라도 1이면 1
^ XOR 두 비트가 서로 다르면 1
~ NOT 모든 비트를 반전 
console.log(5 & 3);  // 1
console.log(5 | 3);  // 7
console.log(5 ^ 3);  // 6
console.log(~5);     // -6

NOT 연산은 비트를 반전한다. JavaScript의 일반적인 Number 비트 연산에서는 ~x가 -(x + 1)과 같으므로 ~5는 -6이다.

5. 쉬프트 연산이란?

쉬프트(Shift)는 비트를 왼쪽이나 오른쪽으로 이동시키는 연산이다.

연산자 이름 기능
<< 왼쪽 쉬프트 왼쪽으로 이동하고 오른쪽 빈자리는 0으로 채움
>> 부호 있는 오른쪽 쉬프트 오른쪽으로 이동하고 왼쪽은 부호 비트로 채움
>>> 부호 없는 오른쪽 쉬프트 오른쪽으로 이동하고 왼쪽 빈자리는 0으로 채움

6. 왼쪽 쉬프트 <<

왼쪽으로 비트를 이동하고, 오른쪽에 생기는 빈자리는 0으로 채운다.

예제 1 : 5 << 1

5 = 0101

왼쪽으로 1비트 이동
0101 → 1010

1010 = 10진수 10

결과 : 5 << 1 = 10

예제 2 : 5 << 2

5 = 00000101

왼쪽으로 2비트 이동
00000101 → 00010100

00010100 = 20

결과 : 5 << 2 = 20

양수에서 비트 손실이나 오버플로가 없으면 왼쪽으로 n비트 이동하는 것은 2ⁿ을 곱하는 것과 같다.

7. 부호 있는 오른쪽 쉬프트 >>

오른쪽으로 비트를 이동한다. 왼쪽 빈자리는 원래 정수의 부호 비트로 채운다.

예제 1 : 20 >> 1

20 = 00010100

오른쪽으로 1비트 이동
00010100 → 00001010

결과 : 10

예제 2 : -5 >> 1

-5의 32비트 2의 보수 표현
11111111 11111111 11111111 11111011

오른쪽으로 1비트 이동
왼쪽은 부호 비트 1로 채움

11111111 11111111 11111111 11111101

결과 : -3

-5 / 2는 -2.5이지만, -5 >> 1은 -3이다. 오른쪽 쉬프트는 부호 있는 정수의 비트를 이동시키므로 일반적인 나눗셈과 결과가 다를 수 있다.

8. 부호 없는 오른쪽 쉬프트 >>>

오른쪽으로 비트를 이동하고, 왼쪽 빈자리는 항상 0으로 채운다.

예제 : -5 >>> 1

-5의 32비트 표현
11111111 11111111 11111111 11111011

오른쪽으로 1비트 이동
왼쪽은 0으로 채움

01111111 11111111 11111111 11111101

결과 : 2147483645

같은 음수라도 >>는 부호 비트를 유지하지만, >>>는 왼쪽을 0으로 채운다. 따라서 결과가 크게 달라질 수 있다.

9. 세 가지 쉬프트 비교

console.log(5 << 1);   // 10
console.log(5 >> 1);   // 2
console.log(5 >>> 1);  // 2

console.log(-5 >> 1);  // -3
console.log(-5 >>> 1); // 2147483645

양수에서는 >>와 >>>가 같은 결과를 내는 경우가 일반적이다. 음수에서는 왼쪽 빈자리를 채우는 방식이 달라 결과가 달라진다.

10. JavaScript의 32비트 처리 규칙

JavaScript의 Number는 기본적으로 IEEE 754 배정밀도 부동소수점 숫자다. 하지만 일반적인 Number 비트 연산에서는 값을 32비트 정수로 변환해 처리한다.

  • <<, >>, &, |, ^, ~ : 부호 있는 32비트 정수 기준
  • >>> : 부호 없는 32비트 정수 기준으로 결과 해석
  • 쉬프트 횟수는 하위 5비트만 사용하므로 사실상 0~31 범위로 처리
console.log(1 << 0);   // 1
console.log(1 << 1);   // 2
console.log(1 << 2);   // 4
console.log(1 << 31);  // -2147483648
console.log(1 << 32);  // 1

1 << 31은 최상위 비트가 1이 되므로 부호 있는 32비트 정수로 해석했을 때 음수가 된다. 1 << 32는 쉬프트 횟수가 0으로 처리되어 1이 된다.

11. BigInt의 쉬프트 연산

BigInt는 큰 정수를 정밀하게 표현하는 타입이다. Number의 일반적인 32비트 비트 연산 제한과 다르게 동작한다.

console.log(1n << 40n);
// 1099511627776n

BigInt 연산에서는 피연산자에 n을 붙이며, 쉬프트 횟수도 BigInt로 지정한다. Number와 BigInt는 비트 연산에서 섞어 사용할 수 없다.

BigInt는 부호 없는 오른쪽 쉬프트 연산자인 >>>를 지원하지 않는다.

12. 쉬프트 연산의 활용

console.log(1 << 0); // 1
console.log(1 << 1); // 2
console.log(1 << 2); // 4
console.log(1 << 3); // 8
console.log(1 << 4); // 16

쉬프트 연산은 비트 플래그, 저수준 데이터 처리, 특정 비트 검사 등에 활용할 수 있다. 다만 일반 웹 개발에서 단순한 곱셈이나 나눗셈을 대체하려고 무조건 사용하는 것은 권장하지 않는다.
